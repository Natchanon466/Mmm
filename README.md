# Microplastic City

เกมบริหารเงินพิชิตเมืองไมโครพลาสติก เกมเพื่อการศึกษาสำหรับนักเรียนประถมปลายถึงมัธยมต้น เล่นเป็น 5 กลุ่ม กลุ่มละประมาณ 5 คน

แต่ละกลุ่มเริ่มด้วยเงิน 1,000 บาทและ Environment 100 คะแนน ต้องตัดสินใจซื้อของและรับมือเหตุการณ์สุ่มในเมือง เพื่อเรียนรู้ว่าการวางแผนเงินและการเลือกของใช้ซ้ำช่วยลดผลกระทบจากขยะพลาสติกได้

เว็บนี้เป็นเครื่องมือของ **ผู้จัดกิจกรรม** ใช้ฉายบนโปรเจกเตอร์เป็นสกอร์บอร์ดและเป็นตัวสุ่มเหตุการณ์ ไม่ต้องติดตั้งหรือมีเซิร์ฟเวอร์ ใช้ HTML, CSS และ JavaScript ล้วน

## วิธีเปิดใช้งาน

ต้องมี Node.js 18 ขึ้นไป (ใช้ได้เฉพาะตอนพัฒนา ตัวเกมไม่ต้องใช้)

```bash
npm start        # เปิดที่ http://localhost:8080
npm test         # ทดสอบกติกาเกม
npm run simulate # จำลองการเล่นซ้ำหลายพันเกม เพื่อเช็กความสมดุลของคะแนน
```

หรือเปิด `index.html` ในเบราว์เซอร์ได้เลย (ฟอนต์จาก Google Fonts ต้องใช้อินเทอร์เน็ต ถ้าไม่มีจะใช้ฟอนต์ของระบบแทน)

## ขั้นตอนการจัดกิจกรรม

1. แท็บ **ผู้จัด** ตั้งชื่อกลุ่ม แล้วกด "เริ่มเกม"
2. ให้กลุ่มซื้อของและใช้จ่ายจริงในห้อง จากนั้นผู้ควบคุมไปที่แท็บ **บันทึกข้อมูล** กรอกเงิน Environment สินค้า และเลขหวยของทุกกลุ่มให้ตรงกับของจริง (ถ้าอยากซื้อผ่านเว็บ ใช้แท็บ **ตลาด** แทนได้)
3. กลับแท็บ **ผู้จัด** กด "สุ่มเหตุการณ์" ดูตัวอย่างผลกระทบของแต่ละกลุ่ม แล้วกด "ยืนยันผลเหตุการณ์"
4. ฉายแท็บ **จอผู้เล่น** ให้ทุกคนเห็นเงิน Environment Inventory และอันดับ
5. ทำซ้ำข้อ 2–4 จนครบจำนวนรอบ แล้วกด "จบเกม" เพื่อดูแท็บ **สรุปผล**

ถ้ากดยืนยันเหตุการณ์ผิด ใช้ปุ่ม **Undo** ได้ก่อนที่จะมีรายการใหม่ (ซื้อ ปรับค่า หรือสุ่มเหตุการณ์ถัดไป)

## กติกาสำคัญ

- **สินค้า:** 9 รายการ แก้ชื่อ ราคา ผลต่อ Environment และเพิ่มสินค้าใหม่ได้ในแท็บ "สินค้าและตั้งค่า"
- **เหตุการณ์:** 21 แบบ ทั้งเสียเงิน ได้เงิน ขึ้นกับสินค้า กระทบทุกกลุ่ม และให้เลือกเอง สุ่มโดยไม่ซ้ำจนครบกอง
- **เงินไม่พอจ่ายเหตุการณ์:** ค่าเริ่มต้นคือจ่ายเท่าที่มีจนเงินเหลือ 0 และหัก Environment เพิ่ม 5 เปลี่ยนเป็นไม่มีโทษเพิ่มได้ในแท็บตั้งค่า
- **หวย:** เลข 0–9 ซื้อได้เลขละ 1 ใบต่อกลุ่ม ต้องให้ทุกกลุ่มยืนยันเลขก่อนจึงสุ่มเลขรางวัลได้ เงินรางวัลเริ่มต้น 200 บาท ควรตั้งไม่เกินราคาซื้อครบทั้ง 10 เลข (200 บาท) ไม่เช่นนั้นการซื้อครบชุดจะได้กำไรแน่นอน
- **คะแนนท้ายเกม (เต็ม 100):**
  - คะแนนเงิน = เงินคงเหลือ ÷ 600 × 50 เงินที่เกิน 600 บาทไม่ได้คะแนนเพิ่ม
  - คะแนน Environment = Environment ÷ 100 × 50
  - คะแนนเท่ากัน กลุ่มที่ Environment สูงกว่าชนะ ถ้ายังเท่ากันถือว่าเสมอ
  - เกณฑ์ 600 ปรับได้ในแท็บตั้งค่า ได้มาจากการจำลองเล่นด้วย `npm run simulate` เพื่อไม่ให้ทั้ง "ไม่ซื้ออะไรเลย" และ "ซื้อของรักษ์โลกทุกชิ้น" ได้เปรียบ

## ข้อมูลถูกเก็บที่ไหน

ข้อมูลเกมเก็บใน `localStorage` ของเบราว์เซอร์เครื่องที่ผู้จัดใช้ รีเฟรชหรือปิดแท็บแล้วยังอยู่ แต่เปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์แล้วจะหาย ไม่มีเซิร์ฟเวอร์และไม่ส่งข้อมูลออกไปที่ใด ปุ่ม "สำรอง/กู้คืนข้อมูล" ในแท็บผู้จัดใช้คัดลอกข้อมูลเก็บไว้ได้

เพราะเก็บแยกตามเบราว์เซอร์ ให้ผู้จัดใช้เครื่องและเบราว์เซอร์เดียวกันตลอดกิจกรรม

## โครงสร้างโปรเจกต์

```
index.html              หน้าเว็บ
css/style.css           สไตล์ (มีโหมดสว่าง/มืดตามระบบ)
js/game.js              ตรรกะเกมและหน้าจอทั้งหมด
tests/game.test.js      ทดสอบกติกา (ซื้อ เหตุการณ์ Undo หวย คะแนน บันทึกข้อมูล)
tools/simulate-balance.js  จำลองการเล่นเพื่อตรวจความสมดุลคะแนน
scripts/serve.js        เซิร์ฟเวอร์ static สำหรับเปิดในเครื่อง
scripts/build.js        คัดลอกไฟล์เผยแพร่ไปที่ _site
.github/workflows/deploy.yml  ทดสอบและขึ้น GitHub Pages อัตโนมัติ
```

## แก้ไขเนื้อหาเกม

- **เหตุการณ์:** อยู่ในอาร์เรย์ `EVENTS` ใน `js/game.js` แต่ละเหตุการณ์มี `title`, `desc`, `rule`, `learn`, `cats` และฟังก์ชัน `calc(group, ctx)` ที่คืนค่า `R(เงิน, Environment, หมายเหตุ)` ถ้าเพิ่มเหตุการณ์ใหม่ ให้เพิ่มการทดสอบใน `tests/game.test.js` ด้วย
- **สินค้าเริ่มต้น:** อยู่ใน `DEFAULT_PRODUCTS` สินค้าที่เหตุการณ์อ้างถึงจะใช้ `id` เช่น `umbrella`, `cup`, `box`, `cleaner`, `bag`, `bin` จึงไม่ควรเปลี่ยน `id`
- **ค่าเริ่มต้นของสูตรคะแนนและหวย:** `initialState()` และฟังก์ชัน `migrate()`

## Deploy ขึ้น GitHub Pages

1. สร้าง repository บน GitHub แล้ว push โค้ดขึ้นสาขา `main`

   ```bash
   git init -b main
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/<ชื่อผู้ใช้>/microplastic-city.git
   git push -u origin main
   ```

2. ที่ repository ไปที่ **Settings → Pages** แล้วตั้ง **Source** เป็น **GitHub Actions** (ทำครั้งเดียว)
3. ทุกครั้งที่ push เข้า `main` workflow จะรัน `npm test` ถ้าผ่านจะ build และเผยแพร่ที่ `https://<ชื่อผู้ใช้>.github.io/microplastic-city/` ส่วน pull request จะรันเฉพาะการทดสอบ

เว็บนี้เป็น static ล้วน ใช้ host อื่นได้เช่นกัน (Netlify, Cloudflare Pages, Vercel) โดยไม่ต้องมี build command และตั้งโฟลเดอร์เผยแพร่เป็นรากของ repository
